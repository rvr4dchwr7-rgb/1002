# 1002 — One Last Year

A private roommate bucket list and memory app for Ella, Keira, Megan, and Tristan.

## Version 1

This first build is a mobile-first web app with:

- Home dashboard
- Shared-style bucket list UI
- Photo album interface
- Our Year timeline
- Memories board
- On-device persistence using localStorage

Cloud sync and private multi-user accounts are planned for the next phase.
